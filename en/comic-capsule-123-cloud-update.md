Added some new features — quick minor version update～

The next version will have something big, so I'm rolling out the quick updates first.

---

## Three New Features

**① 123 Cloud Drive Support**
Super fast speed — if you have 123 Cloud Drive, you can connect directly and start reading.

**② Eye Control Page Turning**
Enable in Settings → General Settings. No hands needed — just move your eyes to turn pages. The ultimate way to read comics lying in bed.

**③ Save Images as Book**
Top-right ＋ Import → Save WeChat/Weibo Images. Found a comic recommendation, fan art, or sketch you like? One tap saves it all as a little book.

---

## Three Bug Fixes

- Fixed stitching issue in PDF high-res mode — no more white lines on split-page images
- Most encrypted ZIP files can now be decrypted — try opening previously inaccessible files again
- Fixed Komga refresh issue — users on Komga should be good to go after updating
