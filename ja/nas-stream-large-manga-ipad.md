# NASに保存された数百GBの漫画をiPadで直接読むには？ダウンロード不要のストリーミング読書ソリューション

NASを1台持っている。その中に数百GBの漫画保存在されている——海贼王的全套100+卷、鬼灭之刃高清收藏版、美丽新世界300+话。整理するだけで数週末がかかった。

そして、iPadで躺在床上看看漫画 싶었다。

ファイルAppを開く → SMBでNASに接続 → 漫画フォルダを見つける → CBZを開く → 「ダウンロード中...」→ 進捗バーが3分間進む → iPadのストレージ不足。

**別のAppでやり直し。还是一样的结果。**

これはあなたの問題ではない。iOS上の漫画Appのほとんどは「まずファイル全体をローカルにダウンロードし、解凍し、表示する」という方式。高画質の漫画CBZは200-500MBで、ダウンロード＋解凍の時間はアニメ1話を視聴できるほど。更に、iPad 64GBのストレージでは数百GBの漫画ライブラリに対応できない。

**しかし、2026年にはすでに更好的方案がある：ストリーミング読書。**

---

## 従来の方案 vs ストリーミング読書：差は有多大？

比較図を見れば、なぜ従来の方式こんなに痛苦的か分かる：

| シーン | 従来ダウンロード-解凍モード | ストリーミング読書モード |
|------|-----------------|------------|
| 300MBのCBZを開く | 300MBダウンロード → 解凍 → 3-5分待つ | 2-3秒バッファリング → すぐ読める |
| 200ページに快速跳转 | 全部解凍しないと跳转できない | 自動プリフェッチでほぼ待ち時間なし |
| 500冊の漫画を同時に保存 | iPadストレージ爆発、到底不可能 | ローカル容量ゼロ、見たい本をタップするだけ |
| 外出先で見たい本が変わる | ファイルAppに戻って、再ダウンロード、再待機 | 3秒切替、ローカルファイル一样的体験 |
| 64GB iPadユーザーの日常 | 2冊見ると削除、削除すると下次またダウンロード | ゼロローカル使用、NASが無限ストレージ |

**核心的区别**：従来モードは「鍋全体の飯を前に出して食べる」、ストリーミング読書は「シェフが一口ずつ盛り付けてくれる、食べる速度＝提供速度、待っている的感觉がない」。

## なぜほとんどのAppがストリーミング読書做不到？

これはApp開発者がやりたくないのではなく、**アーキテクチャ上サポートされていない**から。

漫画の最も一般的なフォーマット——CBZ、ZIP、RAR——は本质上压缩包。従来のリーダーのロジック：

```
1. 圧縮全体をローカル一時ディレクトリにダウンロード
2. 全部の画像ファイルを解压
3. ファイル名でソート
4. 1ページ目から表示
```

ストリーミング読書を実現するには：

```
1. リモート接続を確立し、压缩包的「ディレクトリ領域」のみ読み取り
2. 各画像ファイルの压缩包内のバイトオフセットを記憶
3. ユーザーがどのページをめくるか、そのページのバイト範囲のみリクエスト
4. バックグラウンドで后续ページをプリフェッチし、ページめくりをスムーズにする
```

これには**ネットワークプロトコル、压缩フォーマット内部構造、iOSファイルシステム**の3つに対する深い理解が必要。大多数の漫画Appは既成の解压ライブラリを使用しており、こうした底层最適化を行っていない。漫画胶囊の2人の開発者は大廠后端出身で、まさに「自分がこの機能を必要としている」から、アーキテクチャレベルで整个读取パイプラインを再設計した。

現在App Storeで**ストリーミング読書を実現しているのは漫画胶囊だけ**。

## 実践：3ステップでNAS → iPad ストリーミング読書を実現

### ステップ1：NAS側でプロトコルを確認

NASでは以下の3つのプロトコルのいずれかを有効にする必要がある：

| プロトコル | ほぼすべてのNASがサポート | 設定難易度 | おすすめシナリオ |
|------|:---:|:---:|------|
| **SMB (Samba)** | ✅ 群晖/威联通/极空间/绿联/飞牛/自建 | ⭐ ゼロ設定 | 简单共有、フォルダが书架 |
| **WebDAV** | ✅ NAS后台一键开启 | ⭐⭐ ポート設定必要 | 外网アクセス更适合 |
| **OPDS** | ⚠️ Komga/Kavita搭建必要 | ⭐⭐⭐ Docker必要 | 封面刮削とメタデータ有 |

**初心者にはSMB推荐**——NASはデフォルトで有効になっている、追加設定不要。NASのIPアドレスと共有フォルダ名だけを覚えておく。

### ステップ2：漫画胶囊でNASに接続

1. **漫画胶囊**を開く → 右上の「+」→ ディスクを追加
2. **SMB (Samba)**を選択
3. NASのIPアドレス（例：`192.168.1.100`）と共有フォルダ名（例：`Manga`）を入力
4. NASのログインユーザー名とパスワードを入力
5. 接続をタップ

漫画胶囊がローカルフォルダを閲覧するように、NASの漫画ディレクトリ完整展示される。封面プレビュー、ファイル名、ファイルサイズが表示される。

### ステップ3：ストリーミング読書を開始

任意の漫画をタップ。

**重要**——ダウンロード進捗バー不会出现。2-3秒後、漫画の1ページ目が直接表示される。ページめくりはスムーズで、后面的内容是你阅读时悄悄加载。

これがストリーミング読書の体験：**「リモート」を感じるがない。**

## よくある質問

### Q: 外出先（同じWiFi外）で見られる？

可能、NASのリモートアクセス方案による：

- **群晖QuickConnect**：群晖自带、設定で開くだけ、最も简单
- **Tailscale / ZeroTier**：免费虚拟组网ツール、全デバイスにインストールすると自動接続、強く推荐
- **公网IP + ポート转发**：最も直接だが网络知識が必要
- **代替案**：よく見る漫画を百度网盘/阿里云盘に同期、漫画胶囊も直接网盘をマウントしてストリーミング読書可能

### Q: ストリーミング読書対応の漫画フォーマットは？

CBZ、ZIP、RAR、CBR、EPUB、PDFはすべてストリーミング加载対応。MOBIはローカルにダウンロードして読む必要あり（このフォーマットは本身リモートストリーミング读取不支持、技術的に做不到）。

### Q: ページめくり速度に影響する要素は？

3つの要素：WiFi信号強度、NASのディスク速度、漫画ファイル自体のサイズ。一般的に、ギガビットLAN内ではページめくりはローカルファイルとほぼ同じ速度。遅いと感じる場合は、ルーターから遠すぎないか、NASが大量读写任务しているか確認してください。

### Q: 64GB iPadはまだストレージ不足を提示する？

しない。ストリーミング読書はメモリに当前ページと后续数ページのみバッファリング、iPadストレージを使用しない。数百GBの漫画ライブラリはiPadにとっては存在しないようなもの——見るだけで、ストレージのことはNASに任せて。

## まとめ

NASに保存された数百GBの漫画は「保存して灰尘をためる」のではなく、「随时随地見たい时候見る」。只需要ストリーミング読書対応のAppと15分の一回設定だけ。

```
NAS 保存漫画 → SMB/WebDAV プロトコル → 漫画胶囊 ストリーミング读取 → 3秒で開看、iPad容量不要
```

このことの核心はAppに有多少功能ではなく、**「リモートファイルの即時读取」問題をアーキテクチャレベルで解決できるか**にある。2026年了、もうダウンロードして解压するリーダーで自分を折磨하지ないで。
