# スキャン済み漫画の2ページがくっついてる場合の分け方は？見開き大図の結合方法は？

実はこれは同じ問題の2つの面で、答えは：**ファイルを再処理する必要はなく、リーダー側で解決可能**です。

- **2ページがくっついてる**（1枚の画像に左右1ページずつ）→ 「片面分割」を使うと、自动で2ページに分割して正しい順序でページ送り
- **1枚の絵が見開き2ページにまたがる**（見開き大図が半分に切られている）→ 「下一页合并」を使うと、2枚合わせて1枚の完整な横向き画像に

「漫画カプセル」にはこの2つの機能があるので、それぞれ解説します。

## シーン1：片面スキャン、手机で文字が小さすぎる

多くの实体書のスキャン版は открыт状態でスキャンされており、1枚の画像に左右1ページずつ入っています。iPadの横画面なら辛うじて見れますが、iPhoneの縦画面では頻繁に拡大・ドラッグが必要です。

**解決策**：漫画カプセル の阅读設定で「片面分割」をオンにすると、Appが横長画像を検知して中央の綴じ目で切り離し、2枚の単ページに分割します。**日本漫画は右→左の順序で右ページ부터左ページを順に表示**するので、阅读順序が逆になることはありません。縦画面での漫画阅读が즉시正常になります。

## シーン2：見開き大図が半分に切られている

逆に、多くの素材は単ページに切ってありますが、漫画の名場面——見開き大図——が左右2つに切られており、别々に見ると全くインパクトがありません。

**解決策**：阅读時に「下一页合并」をオンにすると、現在のページと次のページが拼接されて1枚の完整な横向き画像として表示されます。拼接された名場面は**長押しで保存**也能できます（これはバージョン1.41で追加された機能で、壁纸保存に便利です）。

## 併せて読みたい：阅读方向

分割と結合を正しく動作させるには、正しい阅读方向が前提です。クイックチェック：

| コンテンツタイプ | 正しい方向 | 说明 |
|----------|---------|------|
| 日本漫画 | 右 → 左 | 实体書の右開きの習慣 |
| アメリカ漫画/中国漫画ページ漫画 | 左 → 右 | 左開き |
| 縦スクロール漫画/韓国漫画 | 上 → 下 | 連続スクロール、[縦スクロール漫画无缝方案](/zh/blog/webtoon-seam-problem)参照 |

漫画カプセルはデフォルトで日本漫画方向ですが、本ごとに個別設定可能で、各本は自分の方向を記憶します。

## よくある質問 FAQ

**Q：片面分割で見開き大図も誤って分割してしまうことは？**
A：見開き大図は本来就是1枚の連続画像なので、分割すると確かに观赏感が壊れます。このような本の場合は全书で分割をオフにし、横画面片面モードで見るか、または大図が出る時に一時的にオフにしてください。設定は即時反映されます。

**Q：パソコンでツールを使って前処理（比如 ImageMagick で一括切り抜き）が必要ですか？**
A：不要です。分割と結合はレンダリング層で行われ、元のファイルは变动しません。もちろん既に切り抜いた素材はそのまま読めます。

**Q：PDFの片面スキャンは分割できますか？**
A：できます。PDFと画像圧縮ファイル（ZIP/CBZ/CBR）に対応しています。

**Q：iPhoneの縦画面で日本漫画を見る、最適な設定は？**
A：片面分割オン + 余白切り抜きオン + 右→左方向。画面の利用率と阅读順序が両方正解します。
