# NAS 漫画の究極ソリューション：iPadでプライベート漫画庫を瞬時に開く

あなたはNASを持っている。300GBの漫画を保存している。でもiPadで見たいと思ったとき——

ファイルをローカルにダウンロード → 5分待つ → 開く → 形式が合わない → アプリを変える → 再ダウンロード → ストレージが満杯。

**この流れは、2026年に存在するべきではない。**

この記事では、NAS漫画の完全な読書ソリューションを紹介する：NAS側での漫画整理から、iOS側でのストリーミング読書まで、ローカルにファイルを一切ダウンロードする必要はない。準備するものは以下のみ：

- NAS一台（Synology / QNAP / 極空間 / UGREEN / 自宅サーバーでも可）
- iPadまたはiPhone
- 15分の時間

---

## なぜ従来の方法はこんなに苦痛なのか？

始める前に、なぜ「NASで漫画保存 + iPadで閲覧」の組み合わせが常に頭痛の種だったのかを説明する：

    "方法A: SMBファイルアプリ" "ローカルにダウンロード → 5分待つ → アプリを変えて開く → 見終わったら削除"
    "方法B: サードパーティアプリ" "ストリーミング非対応 → 完全ダウンロード必須 → 対応形式が不十分"
    "方法C: Dockerリーダー" "Web版の体験が悪い → タッチ操作が非対応 → ページめくりがカクつく"
    
核心的な矛盾：**iOSエコシステムには、NASの漫画を直接ストリーミングできるプロフェッショナルなリーダーが存在しない**。漫画胶囊がこの問題を解決するまで。

---

## 解決策：三種の神器で全てを解決

## ステップ1: NAS側 — 漫画ライブラリを整理

### 方法A: シンプルで大雑把なタイプ（初心者におすすめ）

漫画ファイルをフォルダごとに分類してNASの共有ディレクトリに置き、SMBまたはWebDAVプロトコルでマウントする。

```
📁 /Manga/
  ├── 📁 ワンピース/
  │   ├── ワンピース_第1巻.cbz
  │   ├── ワンピース_第2巻.cbz
  │   └── ...
  ├── 📁 鬼滅の刃/
  │   ├── 鬼滅の刃_01.cbz
  │   └── ...
  └── 📁 SPY×FAMILY/
      ├── SPY×FAMILY_第1巻.epub
      └── ...
```

**メリット**：初期設定不要、フォルダがそのまま本棚になる
**デメリット**：カバー画像の自動取得がない、管理は手動

### 方法B: プロフェッショナルメディアサーバータイプ（ヘビーユーザーにおすすめ）

漫画専用のメディアサーバーを構築し、カバー画像・メタデータの自動取得、マルチユーザー対応。

| サーバー | 特徴 | 対象ユーザー | iOSクライアント |
|--------|------|---------|----------|
| **Komga** | 漫画専用設計、Webリーダー優良、OPDS対応 | 漫画コレクター | 漫画胶囊(OPDS) |
| **Kavita** | 万能型、漫画+電子書籍対応、モダンなUI | 総合読書ユーザー | 漫画胶囊(OPDS) |
| **極漫画** (極空間内蔵) | NAS標準搭載、設定不要 | 極空間ユーザー | 漫画胶囊(WebDAV) |
| **Calibre-Web** | 電子書籍管理、漫画形式対応 | Calibreユーザー | 漫画胶囊(OPDS) |

**DockerでKomgaをデプロイする例**（Synology / QNAP共通）：

```yaml
version: '3'
services:
  komga:
    image: gotson/komga:latest
    container_name: komga
    volumes:
      - /volume1/docker/komga/config:/config
      - /volume1/Manga:/data
    ports:
      - "25600:25600"
    restart: unless-stopped
```

デプロイ後、`http://あなたのNAS-IP:25600` にアクセスし、漫画ライブラリのパスを設定すると、Komgaが自動的にスキャンしてカバー画像を生成します。

## ステップ2: iOS側 — 接続してストリーミング読書

これは全体のソリューションの中で最も重要なステップです。**NASプロトコル + ストリーミング読書**に対応したiOS漫画リーダーが必要です。

### 漫画胶囊の設定（3分で完了）

**方法1: WebDAV接続**

Synology、fnOS、極空間など、ほとんどのNASにはWebDAVサービスが内蔵されています：

1. 漫画胶囊を開く → 右上の「ディスク追加」→ **WebDAV**を選択
2. NASのWebDAVアドレスを入力（例：`https://192.168.1.100:25600`）
3. ユーザー名とパスワードを入力
4. 完了！これでNAS上の漫画ディレクトリを直接閲覧できます

**方法2: SMB接続**

SMBはWebDAVサービスと非常に似ています：

1. ディスク追加 → **SMB (Samba)**を選択
2. NASのIPアドレスと共有フォルダ名を入力
3. NASのログインIDとパスワードを入力
4. 完了！

**方法3: OPDS接続**

Komga / Kavita / Calibre-Webを構築している場合：

1. ディスク追加 → **OPDS**を選択
2. OPDSアドレスを入力（例：`http://192.168.1.100:25600/opds/v2.0/catalog`）
3. 完了！カバー画像とメタデータを自動取得

### ストリーミング読書体験

接続後、任意の漫画を開くと——

**ダウンロードを待つ必要はありません。** 漫画胶囊は自動的に最初の数ページをバッファし、2〜3秒後にはページをめくり始められます。以降の内容は閲覧中にバックグラウンドで静かに読み込まれ、全体のプロセスはスムーズでストレスがありません。

これは一冊で数百MBもある高解像度の漫画にとって、体験の向上は**革命的**です。以前は他のアプリで数十秒から数分待つこともありましたが、今はほぼ即座に開きます。

> 💡 **技術解説**：漫画胶囊のストリーミング読書は動画サイトの原理と似ています——CBZ/ZIP圧縮ファイル内の画像を順番にプリフェッチし、現在のページと後続の数ページのみを読み込みます。これにより「ファイル全体を解凍しなければならない」という制限を回避します。現在App Storeでこの機能を実現しているのは漫画胶囊だけです。

## ステップ3: さらなる最適化

### AI高画質化：古い漫画を再生

多くの古い漫画のスキャン画像は品質が低い——黄ばみ、ぼやけ、網点の粗さがあります。漫画胶囊内蔵の**端末内AI高画質化**は、iPad/iPhone上で直接画像を超解像処理できます。

有効方法：リーダー内で2本指でタップ → 「AI高画質化」を選択 → 数秒待って処理完了。

デバイス上で直接モデルを実行するため（クラウドを経由しない）、以下の利点があります：
- 🔒 漫画コンテンツはどのサーバーにもアップロードされません
- 📶 ネットワーク接続は不要
- ⚡ 処理速度はデバイス性能に依存（MチップMac > iPad Pro > iPhone）

### 自動白辺カット + 縦読み最適化

- **白辺カット**：漫画ページの余分な余白を自動検出して切り取り、画面を埋めます
- **縦読みモード**：韓国漫画・中国漫画を読むときに自動的に上下スクロールモードへ切り替え、比率も自動調整

### 複数デバイスでの読書進捗同期

漫画胶囊はiCloudで読書進捗を同期します。iPadで87ページまで読んだら、外出先でiPhoneで同じ本を開くと、自動的に前回の位置にジャンプします。（同じApple IDが必要）

## よくある質問 FAQ

### Q: 外部（家庭のWiFi以外）でNASの漫画を見られますか？

可能ですが、以下の条件のいずれかが必要です：
- NASがパブリックIPを持ち、ポート転送を設定している（ある程度のネットワーク知識が必要）
- Tailscale / ZeroTierなどの仮想ネットワーキングツールを使用
- Synology QuickConnectなどNAS内蔵のリモートアクセスサービスを使用
- よく読む漫画をBaidu Cloud / Alibaba Cloud Driveにバックアップし、漫画胶囊でクラウドドライブをマウント（ストリーミング読書にも対応）

### Q: WebDAV、SMB、OPDSの3つのプロトコル、どれを選ぶべき？

| プロトコル | 使用シーン | おすすめ度 |
|------|---------|:---:|
| **OPDS** | Komga / Kavita / Calibre-Webを構築している場合 | ⭐⭐⭐ 最良、カバーとメタデータあり |
| **WebDAV** | Synology/QNAP内蔵、またはKomgaのWebDAV | ⭐⭐ 便利、多くのNASが対応 |
| **SMB** | シンプルな共有フォルダ、追加設定不要 | ⭐ 使えるが、機能は最小限 |

### Q: Android / Windowsでもこのソリューションは使えますか？

漫画胶囊は現在iOS / iPadOS / macOS (Apple Silicon)のみ対応です。AndroidユーザーはPerfect Viewer + SMBプラグイン、またはMihon + Komga拡張機能を検討できます。

```
NAS保存 → 漫画胶囊がストリーミング読み取り → 待ち時間なし、ダウンロード不要、画質もAIで強化
```
