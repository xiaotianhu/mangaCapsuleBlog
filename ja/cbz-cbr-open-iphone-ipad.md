# iPhone/iPad で CBZ、CBR ファイルが開けない？漫画フォーマットを完全解説

答えは：**CBZ/CBR は漫画専用のアーカイブ形式。iOS標準の「ブック」Appと「ファイル」Appは対応していないため、漫画リーダーが必要**です。対応リーダー（例：「漫画胶囊」）をインストールし、ファイルを共有またはインポートすれば、解凍や変換なしでそのまま読めます。

## CBZ/CBR とは？

很简单：

- **CBZ** = Comic Book Zip、**ZIP アーカイブ**の拡張子を変えたもの，内部は連番の漫画画像
- **CBR** = Comic Book Rar，同样、**RAR アーカイブ**の拡張子を変えたもの

拡張子を変更することで、リーダーが「これは漫画だ」と認識し、ページ順にレンダリングできるようになります。普通のアーカイブファイルとしては扱いません。理论上、.cbz を .zip に戻して解凍也能取出图片——不过，一枚一枚画像をギャラリーで見ていたら 불편합니다。

## なぜ iOS では開けない？

- 「ブック」App は EPUB と PDF のみ対応
- 「ファイル」App は ZIP の解压 가능だが、CBZ 拡張子は認識しない；解压也只能在プレビュー中单张看图
- App Store の汎用圧縮ツールは解压できるが、漫画阅读体验がない（方向、双页、进度）

## 正しい方法：三ステップ

1. **漫画リーダーを入れる**：App Store で「漫画胶囊」を検索（免费下载、CBZ/CBR 対応、ZIP/RAR/7Z/PDF/EPUB/MOBI/AZW3 など 10+ フォーマット対応）
2. **ファイルをインポート**、方法は自由：
   - 微信/QQ/ブラウザでファイルを受け取る → 共有メニュー → 「漫画胶囊」
   - 电脑传输 → WiFi 伝书（同局域网网页拖拽上传）或 USB データケーブル
   - ファイルが网盘/NASにある → 直接マウント可能、インポート不要（文末関連記事を参照）
3. **タップして読書**：自動生成封面、進捗を記憶、日漫方向・見開き・余白切り取り対応

## よくあるご質問 FAQ

**Q：CBZ は先に解压が必要？**
A：不要です。漫画リーダーが直接アーカイブ内部を読み取り、ストリーミング加载——数百MBのファイルも瞬時に開きます。

**Q：CBR が「ファイル损坏」で開くことができない場合は？**
A：まずダウンロード不完整を疑う（ファイルサイズを比較）、次に分割アーカイブの片方のみダウンロードした可能性あり。[ファイル损坏のよくある原因](/zh/blog/blog-brokenfile)を参照してください。

**Q：cbz と zip 、どちらのフォーマットで漫画を保存更好？**
A：内容は同じなので好みでOK。他人に共有する場合は .cbz がおすすめ、意味が明確；NASに保存する場合は .zip でも問題ありません。

**Q：数GBのCBZコレクションを iPhone で開ける？**
A：開けます。ストリーミング加载はファイルを全部メモリに読み込む必要がないため、大容量ファイルもタップ即表示；NAS/网盘に保存すれば本体容量も節約できます。
