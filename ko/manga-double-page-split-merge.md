# 스캔판 만화의 두 페이지가 붙어 있으면 어떻게 분리할까? 크로스페이지 대형 이미지는 어떻게 병합할까?

사실 이것은 같은 문제의 두 가지 방향이며, 답은 모두 같습니다: **파일을 다시 처리할 필요 없이 리더기 레벨에서 해결 가능**.

- **두 페이지가 붙어 있음** (한 이미지 안에 왼쪽과 오른쪽 각一页) → «이중 페이지 분할»을 사용하면 자동으로 두 페이지로切り裂어 올바른 순서로めくることができます
- **한 그림이 두 페이지에 걸쳐 있음** (크로스페이지 대형 이미지가 반으로 잘림) → «다음 페이지 병합»을 사용하면 두 장을 하나의 완전한 가로 이미지로 다시 합칠 수 있습니다

«漫画胶囊»에는 이 두 기능이 모두 있으므로, 각각 설명하겠습니다.

## 시나리오 1: 이중 스캔, 모바일에서文字이 너무 작음

很多实体书扫描版是摊开扫的，一张图片就是左右两页。iPad 가로 모드에서는 어떻게든 볼 수 있지만, iPhone 세로 모드에서는 계속 확대하고 드래그해야 합니다.

**해결책**:漫画胶囊 의 읽기 설정에서 «이중 페이지 분할»을 활성화하세요. 앱이 넓은 이미지를 감지하면 자동으로 중앙에서 잘라 두 개의 단일 페이지로 분리합니다; **일본 만화는 오른쪽→왼쪽 순서로 먼저 오른쪽 페이지를 표시한 다음 왼쪽 페이지를 표시**하므로 읽기 순서가 뒤집히지 않습니다. 세로 모드에서 만화를 읽는 경험이 즉시 정상적으로 바뀝니다.

## 시나리오 2: 크로스페이지 대형 이미지가 반으로 잘림

반대로, 많은 리소스는 단일 페이지로 잘린 상태이지만, 만화의 명场面——크로스페이지 대형 이미지——이 왼쪽과 오른쪽으로 반씩 잘려 있어 따로 보면 전혀 임팩트가 없습니다.

**해결**: 읽을 때 «다음 페이지 병합»을 활성화하면 현재 페이지와 다음 페이지가 하나의 완전한 가로 이미지로 표시됩니다. 만들어진 명场面은 **길게 눌러 저장**하여 하나의 완전한 이미지로 저장할 수 있습니다 (이것은 1.41 버전에서 추가된 것으로, 월papers 저장에非常好用).

##附带说一下: 읽기 방향

페이지 분할과 병합이 올바르게 작동하려면, 먼저 읽기 방향이 맞아야 합니다. 빠른 확인:

| 콘텐츠 유형 | 올바른 방향 | 설명 |
|----------|---------|------|
| 일본 만화 | 오른쪽 → 왼쪽 | 실물책 오른쪽 펼치기的习惯 |
| 미국 만화/중국 만화 페이지 만화 | 왼쪽 → 오른쪽 | 왼쪽 펼치기 |
| 웹툰/한국 만화 | 위 → 아래 | 연속 스크롤, [웹툰 무결점 솔루션](/zh/blog/webtoon-seam-problem) 참조 |

漫画胶囊는 기본적으로 일본 만화 방향을 사용하지만, 책별로 개별 설정이 가능하며, 각 책은 자신의 방향을 기억합니다.

## 자주 묻는 질문 FAQ

**Q: 이중 페이지 분할이 크로스페이지 대형 이미지도 잘못 분리하지 않을까요?**
A: 크로스페이지 대형 이미지는 본래 하나의 연속적인 화면이므로, 분리하면 확실히 시각적 느낌이 깨집니다. 이런 책의 경우 전체에서 분할을 끄고 가로 모드 이중 페이지 모드로 보는 것을 권장합니다; 또는 대형 이미지를 만날 때 일시적으로 끄면 설정이 즉시 적용됩니다.

**Q: 컴퓨터에서 도구로 사전 처리해야 하나요 (예: ImageMagick으로 배치 이미지 자르기)?**
A: 필요 없습니다. 분할과 병합은 모두 렌더링 레이어에서 발생하며, 원본 파일은 변경되지 않습니다. 当然你已经切好的资源直接读也完全没问题.

**Q: PDF의 이중 페이지 스캔을 분리할 수 있나요?**
A: 가능합니다. PDF와 이미지 압축 파일 (ZIP/CBZ/CBR)을 모두 지원합니다.

**Q: iPhone 세로 모드에서 일본 만화를 볼 때 가장舒适的 설정은 무엇인가요?**
A: 이중 페이지 분할 활성화 + 테두리 자르기 활성화 + 오른쪽→왼쪽 방향. 화면 활용률과 읽기 순서가 모두 맞습니다.
