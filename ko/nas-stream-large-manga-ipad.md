# NAS에 수백GB漫画를 iPad에서 바로 보는 방법은? 다운로드 없는 스트리밍 읽기 솔루션

NAS 한 대가 있습니다. 안에 수백GB의漫画가 저장되어 있습니다——원피的全套 100+권, 귀멸의刃 고화질 수집판, 아름다운 신세계 300+화. 정리하는 것만으로도 여러 주말이 걸렸습니다.

그다음 침대에서 iPad로 보고 싶습니다.

파일 앱 열기 → SMB로 NAS 연결 →漫画 폴더 찾기 → CBZ 파일 하나 열기 → «다운로드 중...» → 진행 표시줄이 3분 동안 기어다님 → iPad 저장 공간 부족.

**다른 앱으로 다시 해보기. 결과는 마찬가지입니다.**

이건 당신의 문제가 아닙니다. iOS의 대부분의漫画 앱 작동 방식은 «먼저 전체 파일을 로컬에 다운로드하고, 압축을 푼 다음, 표시»입니다. 고화질漫画 CBZ는 하나당 200-500MB로, 다운로드 + 압축 해제 시간에 애니메이션 한 편을 다 볼 수 있습니다. 게다가 iPad 64GB 저장 공간은 수백GB의漫画 라이브러리를 감당하지 못합니다.

**하지만 2026년에는 더 좋은 솔루션이 있습니다: 스트리밍 읽기.**

---

## 전통적인 솔루션 vs 스트리밍 읽기: 차이가 얼마나 될까?

비교표를 보면 왜 전통적인 방식이 이렇게痛苦的인지 알 수 있습니다:

| 시나리오 | 전통적인 다운로드-압축 해제 모드 | 스트리밍 읽기 모드 |
|------|-----------------|------------|
| 300MB CBZ 한 권 열기 | 300MB 다운로드 → 압축 해제 → 3-5분 대기 | 2-3초 버퍼링 → 바로 보기 |
| 200페이지로 빠르게 넘기기 |全部解压完了才能跳转 | 자동 사전 가져오기, 거의 대기 없음 |
| 500권漫画 동시에 저장 | iPad 저장 공간 폭발, 불가능 | 로컬 공간 점유 안 함, 원하는 책 바로 선택 |
| 밖에서 갑자기 다른 책 보고 싶을 때 | 파일 앱으로 돌아가기, 다시 다운로드, 다시 대기 | 3초 전환, 로컬 파일 경험과 동일 |
| 64GB iPad 사용자 일상 | 두 권 보면 지우고, 지우면下次 다시 다운로드 | 로컬 점유 제로, NAS가 무한 저장소 |

**핵심 차이**: 전통 모드는 «먼저 밥 전체를 가져다놓고 먹기», 스트리밍 읽기는 «요리사가 한 숟갈씩 떠주며, 먹는 속도 = 서빙 속도, 기다리는 줄도 모름».

## 대부분의 앱이 스트리밍 읽기를 못하는 이유는?

앱 개발자가 하고 싶어 안 하는 게 아니라,**아키텍처적으로 지원이 안 됩니다**.

漫画의 가장 일반적인 형식——CBZ, ZIP, RAR——은 본질적으로 압축 파일입니다. 전통적인 리더의 로직은:

```
1. 전체 압축 파일을 로컬 임시 디렉토리에 다운로드
2. 모든 이미지 파일 압축 해제
3. 파일 이름순으로 정렬
4. 첫 페이지부터 표시
```

스트리밍 읽기를 구현하려면:

```
1. 원격 연결을 구축하고 압축 파일의 «디렉토리 영역»만 읽기
2. 각 이미지가 압축 파일 내의 바이트 오프셋 기억
3. 사용자가 어느 페이지를 펼치면 해당 페이지에 해당하는 바이트 범위만 요청
4.后台预取后续几页，保证翻页不卡顿
```

이것은**네트워크 프로토콜, 압축 형식 내부 구조, iOS 파일 시스템**세 가지에 대해 깊은 이해가 필요합니다. 대부분의漫画 앱은 완성된 압축 해제 라이브러리를 사용해서 이런 저수준 최적화가 전혀 되어 있지 않습니다.漫画胶囊의 두 개발자는 대기업 백엔드 출신으로, «스스로 이 기능이 필요해서» 아키텍처 수준에서 전체 읽기 파이프라인을 다시 설계했습니다.

현재 App Store에서**스트리밍 읽기를真正实现한 것은漫画胶囊뿐입니다**.

## 실전: 세 단계로 NAS → iPad 스트리밍 읽기 설정

### 첫 번째 단계: NAS 측 프로토콜 확인

NAS에서 다음 세 가지 프로토콜 중 하나를 활성화해야 합니다:

| 프로토콜 | 거의 모든 NAS 지원 | 설정 난이도 | 추천 시나리오 |
|------|:---:|:---:|------|
| **SMB (Samba)** | ✅ Synology/QNAP/极空间/绿联/飞牛/自建 | ⭐ 설정 불필요 | 간단한 공유, 폴더가 책장 |
| **WebDAV** | ✅ NAS后台一键开启 | ⭐⭐ 포트 설정 필요 | 외부 접근 더友好 |
| **OPDS** | ⚠️ Komga/Kavita 설치 필요 | ⭐⭐⭐ Docker 필요 | 커버 스크래핑 및 메타데이터 있음 |

**초보자는 SMB 추천**——NAS가 기본으로 이미 열려 있어서 추가 설정이 필요 없습니다. NAS의 IP 주소와 공유 폴더 이름만 기억하면 됩니다.

### 두 번째 단계:漫画胶囊에서 NAS 연결

1. **漫画胶囊** 열기 → 우측 상단 «+» → 디스크 추가
2. **SMB (Samba)** 선택
3. NAS의 IP 주소(예: `192.168.1.100`)와 공유 폴더 이름(예: `Manga`) 입력
4. NAS 로그인 계정 비밀번호 입력
5. 연결 클릭

漫画胶囊이 로컬 폴더를 탐색하듯 NAS漫画 디렉토리를完整하게 보여줍니다. 커버 미리보기, 파일 이름, 파일 크기가 있습니다.

### 세 번째 단계: 스트리밍 읽기 시작

원하는漫画 한 권을 엽니다.

**중요한 점**——다운로드 진행 표시줄이 안 보입니다. 2-3초 후,漫画 첫 페이지가 바로 나타납니다. 페이지 넘김이 부드럽고流畅,后面的内容在你阅读时后台悄悄加载.

이것이 스트리밍 읽기의 경험입니다:**«원격»을 느끼지 못합니다.**

## 자주 묻는 질문

### Q: 집이 아니同一个 WiFi에서 볼 수 있을까?

가능합니다. NAS 원격 접근 솔루션에 따라 다릅니다:

- **Synology QuickConnect**: Synology 기본 제공, 설정에서 열면 됨, 가장 간단함
- **Tailscale / ZeroTier**: 무료 가상 네트워킹 도구, 모든 기기에 설치하면 자동 연결, 강력 추천
- **공인 IP + 포트 포워딩**: 가장 직접적이지만 네트워크 지식 필요
- **대안**: 자주 보는漫画를 Baidu网盘/阿里云盘에 동기화,漫画胶囊도网盘 직접 마운트 스트리밍 읽기 지원

### Q: 스트리밍 읽기는 어떤漫画 형식을 지원하나요?

CBZ, ZIP, RAR, CBR, EPUB, PDF 모두 스트리밍 로딩 지원. MOBI는 로컬에 다운로드해서 읽어야 함(このフォーマット本身不支持远程流式读取, 기술적으로 불가능함).

### Q: 페이지 넘기기 속도에 무엇이 영향을 주나요?

세 가지 요인: WiFi 신호 강도, NAS의 하드 디스크 속도,漫画 파일 자체 크기. 일반적으로 기가비트 랜 내에서 페이지 넘기기는 로컬 파일과 거의 동일하게 빠름. 느리다고 느껴지면 라우터에서 너무 멀리 떨어져 있거나 NAS가大量读写 작업을 하고 있는지 확인하세요.

### Q: 64GB iPad도 여전히 저장 공간 부족 안내가 뜨지 않을까요?

안 뜹니다. 스트리밍 읽기는 메모리에 현재 페이지와 다음 몇 페이지만 버퍼링하고, iPad 저장 공간을 점유하지 않습니다. 수백GB의漫画 라이브러리가 iPad에게는 마치 존재하지 않는 것과 같습니다——보는 것만 하면 되고, 저장은 NAS에게 맡기세요.

## 정리

NAS에 있는 수数百GB漫画는 «저장해 두기»가 아니라——«언제 어디서나 보고 싶을 때 바로 보기»입니다. 스트리밍 읽기를 지원하는 앱과 15분的一次性 설정만 있으면 됩니다.

```
NAS에漫画 저장 → SMB/WebDAV 프로토콜 →漫画胶囊 스트리밍 읽기 → 3초 만에 보기, iPad 공간 점유 없음
```

이것의 핵심은 앱에 기능이 얼마나 많은지가 아니라,**아키텍처 수준에서 «원격 파일即时读取» 문제를 해결할 수 있느냐**입니다. 2026년이 되어서야 다운로드 후 압축 해제해야 하는 리더로 자신을 괴롭히지 마세요.
