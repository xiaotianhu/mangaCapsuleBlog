# NAS 만화 궁극 솔루션: iPad에서 개인 만화 라이브러리를 즉시 열기

당신은 NAS를 가지고 있습니다. 300G의 만화를 저장했습니다. 하지만 iPad에서 보고 싶을 때——

파일을 로컬로 다운로드 → 5분 대기 → 열기 → 형식이 맞지 않음을 발견 → 앱 변경 → 다시 다운로드 → 저장 공간이 가득 참.

**이 과정은 2026년에는 더 이상 존재해서는 안 됩니다.**

이 글은 완전한 NAS 만화 읽기 솔루션을 제공합니다: NAS에서 만화 정리부터 iOS에서 스트리밍 읽기까지, 로컬에 어떤 파일도 다운로드할 필요가 없습니다. 준비해야 할 것은 다음과 같습니다:

- NAS 한 대 (Synology / QNAP / UGREEN / Zspace / 자체 구축 모두 가능)
- iPad 또는 iPhone 한 대
- 15분의 시간

---

## 왜 기존 솔루션이 이렇게 고통스러울까?

시작하기 전에, 왜 'NAS에 만화 저장 + iPad로 보기' 조합이 항상 골칫거리였는지 설명하겠습니다:

    "方案A: SMB 파일 앱" "로컬에 다운로드 → 5분 대기 → 앱 바꿔서 열기 → 보고 삭제"
    "方案B: 서드파티 앱" "스트리밍 미지원 → 전체 다운로드 필요 → 형식 지원 불완전"
    "方案C: Docker 리더기" "웹 경험 낮음 → 터치 비적응 → 페이지 넘김 버벅임"
    
핵심 모순은: **iOS 생태계에 NAS 만화를 직접 스트리밍 읽기 할 수 있는 전문 리더기가 없다는 것**입니다. 만화 캡슐이 이 문제를 해결할 때까지는.

---

## 솔루션: 3종 세트로 모든 것 해결

## 1단계: NAS 측 — 만화 라이브러리 정리

### 방법 A: 단순하고 직접적인 유형 (초보자 추천)

만화 파일을 폴더별로 분류하여 NAS의 공유 디렉토리에 배치하고, SMB 또는 WebDAV 프로토콜로 마운트합니다.

```
📁 /Manga/
  ├── 📁 원피스/
  │   ├── 원피스_제1권.cbz
  │   ├── 원피스_제2권.cbz
  │   └── ...
  ├── 📁 귀멸의 칼날/
  │   ├── 귀멸의 칼날_01.cbz
  │   └── ...
  └── 📁 스파이 패밀리/
      ├── 스파이 패밀리_제1권.epub
      └── ...
```

**장점**: 설정 없음, 폴더가 곧 책장
**단점**: 커버 스크래핑 없음, 관리 수동

### 방법 B: 전문 미디어 서버 유형 (헤비 유저 추천)

만화 전용 미디어 서버를 구축하여 커버, 메타데이터를 자동으로 스크래핑하고 다중 사용자를 지원합니다.

| 서버 | 특징 | 적합한 사용자 | iOS 클라이언트 |
|--------|------|---------|----------|
| **Komga** | 만화 전용 설계, 웹 리더기 우수, OPDS 지원 | 만화 수집가 | 만화 캡슐(OPDS) |
| **Kavita** | 올라운더, 만화+전자책 지원, 모던 UI | 종합 독서 사용자 | 만화 캡슐(OPDS) |
| **극만화** (Zspace 내장) | NAS 내장, 배포 불필요 | Zspace 사용자 | 만화 캡슐(WebDAV) |
| **Calibre-Web** | 전자책 관리, 만화 형식 지원 | Calibre 사용자 | 만화 캡슐(OPDS) |

**Docker로 Komga 배포 예시** (Synology/QNAP 공통):

```yaml
version: '3'
services:
  komga:
    image: gotson/komga:latest
    container_name: komga
    volumes:
      - /volume1/docker/komga/config:/config
      - /volume1/Manga:/data
    ports:
      - "25600:25600"
    restart: unless-stopped
```

배포 후 `http://당신의NAS-IP:25600`에 접속하여 만화 라이브러리 경로를 설정하면, Komga가 자동으로 스캔하여 커버를 생성합니다.

## 2단계: iOS 측 — 연결 및 스트리밍 읽기

이것은 전체 솔루션에서 가장 중요한 단계입니다. **NAS 프로토콜 + 스트리밍 읽기**를 지원하는 iOS 만화 리더기가 필요합니다.

### 만화 캡슐 설정 (3분이면 완료)

**방법 1: WebDAV 연결**

Synology, Feiniu, Zspace 등 모든 NAS에는 WebDAV 서비스가 내장되어 있습니다:

1. 만화 캡슐 열기 → 오른쪽 위 디스크 추가 → **WebDAV** 선택
2. NAS의 WebDAV 주소 입력 (예: `https://192.168.1.100:25600`)
3. 사용자 이름과 비밀번호 입력
4. 완료! 이제 NAS의 만화 디렉토리를 바로 탐색할 수 있습니다

**방법 2: SMB 연결**

SMB는 WebDAV 서비스와 매우 유사합니다:

1. 디스크 추가 → **SMB (Samba)** 선택
2. NAS의 IP 주소와 공유 폴더 이름 입력
3. NAS 로그인 계정과 비밀번호 입력
4. 완료!

**방법 3: OPDS 연결**

Komga / Kavita / Calibre-Web을 구축했다면:

1. 디스크 추가 → **OPDS** 선택
2. OPDS 주소 입력 (예: `http://192.168.1.100:25600/opds/v2.0/catalog`)
3. 완료! 커버와 메타데이터 자동 획득

### 스트리밍 읽기 경험

연결 후, 아무 만화나 탭하면——

**다운로드를 기다릴 필요가 없습니다.** 만화 캡슐이 처음 몇 페이지를 자동으로 버퍼링하여 2-3초 후에 페이지 넘김이 가능합니다. 이후 내용은 보는 동안 백그라운드에서 조용히 로드됩니다. 전체 과정이 부드럽고 자연스럽습니다.

이것은 한 권에 수백 MB에 달하는 고화질 만화의 경우 체감이 **혁명적**입니다. 이전에는 다른 앱으로 수십 초 또는 몇 분을 기다려야 했지만, 이제는 기본적으로 즉시 열립니다.

> 💡 **기술 설명**: 만화 캡슐의 스트리밍 읽기는 비디오 사이트와 유사한 원리입니다——CBZ/ZIP 압축 파일 내부의 이미지를 순서대로 프리페치하여 현재 페이지와 다음 몇 페이지만 로드합니다. 이로써 '전체 파일을 먼저 압축 해제해야 한다'는 제약을 우회합니다. 현재 App Store에서 이 기능을 구현한 것은 만화 캡슐뿐입니다.

## 3단계: 고급 최적화

### AI 고화질: 오래된 만화에 새 생명 불어넣기

많은 오래된 만화의 스캔 품질이 높지 않습니다——누렇게 변하고, 흐릿하고, 점 패턴이 거칠습니다. 만화 캡슐에 내장된 **디바이스 측 AI 고화질**은 iPad/iPhone에서 직접 이미지를 초고해상도 처리할 수 있습니다.

활성화 방법: 리더기에서 두 손가락으로 가볍게 탭 → 'AI 고화질' 선택 → 몇 초간 처리 완료.

기기에서 직접 모델을 실행하기 때문에 (클라우드를 거치지 않음):
- 🔒 만화 내용이 어떤 서버에도 업로드되지 않습니다
- 📶 네트워크 연결 불필요
- ⚡ 처리 속도는 디바이스 성능에 따라 다름 (M 칩 Mac > iPad Pro > iPhone)

### 자동 여백 제거 + 세로 스크롤 최적화

- **여백 제거**: 만화 페이지의 불필요한 여백을 자동 감지하여 잘라내어 화면을 가득 채웁니다
- **세로 스크롤 모드**: 한국/중국 만화를 볼 때 자동으로 상하 스크롤 모드로 전환, 비율 자동 적응

### 다중 디바이스 읽기 진행 상황 동기화

만화 캡슐은 iCloud를 통해 읽기 진행 상황을 동기화합니다. iPad에서 87페이지를 보고, 나가서 iPhone으로 같은 책을 열면 자동으로 마지막으로 읽은 위치로 이동합니다. (동일한 Apple ID 필요)

## 자주 묻는 질문 FAQ

### Q: 외부 (집 WiFi가 아닌 곳)에서 NAS의 만화를 볼 수 있나요?

가능하지만, 다음 조건 중 하나를 충족해야 합니다:
- NAS에 공인 IP가 있고 포트 포워딩이 설정된 경우 (일정 네트워크 지식 필요)
- Tailscale / ZeroTier 등 가상 네트워킹 도구 사용
- Synology QuickConnect 등 NAS 내장 원격 액세스 서비스 사용
- 자주 보는 만화를 Baidu Netdisk / Aliyun Drive에 백업하고, 만화 캡슐에서 클라우드 드라이브를 마운트 (스트리밍 읽기 동일 지원)

### Q: WebDAV, SMB, OPDS 세 프로토콜 중 어떤 것을 선택할까?

| 프로토콜 | 사용 시나리오 | 추천도 |
|------|---------|:---:|
| **OPDS** | Komga / Kavita / Calibre-Web 구축한 경우 | ⭐⭐⭐ 최고, 커버 및 메타데이터 포함 |
| **WebDAV** | Synology/QNAP 내장, 또는 Komga의 WebDAV | ⭐⭐ 편리, 대부분의 NAS 지원 |
| **SMB** | 간단한 공유 폴더, 추가 설정 원하지 않을 때 | ⭐ 사용 가능하지만 기능 가장 기본 |

### Q: Android / Windows에서 이 솔루션을 사용할 수 있나요?

만화 캡슐은 현재 iOS / iPadOS / macOS (Apple Silicon)만 지원합니다. Android 사용자는 Perfect Viewer + SMB 플러그인 또는 Mihon + Komga 확장을 고려할 수 있습니다.
