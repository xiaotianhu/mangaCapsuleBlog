# 123 클라우드 드라이브 만화를 iPad/iPhone에서 보는 방법? 직접 읽기 마운트 튜토리얼

「만화 캡슐」은 26년 6월 버전부터 123 클라우드 드라이브 마운트를 지원합니다!
앱에서 권한 로그인 후, 클라우드 드라이브의 ZIP/CBJ/PDF 만화를 바로 책장으로 매핑하여 스트리밍 읽기 가능, 로컬에 다운로드할 필요 없이 읽을 수 있습니다.

123 클라우드 드라이브는 최근 「무제한 무료 속도」라는 포지션으로 리소스를 저장하는 사용자를 많이 확보했고, 만화 리소스 공유도 점점 많아지고 있습니다. 하지만 다른 클라우드 드라이브와 마찬가지로, 공식 앱에서 만화를 보기에는 너무 불편합니다. 압축 파일을 온라인으로解压할 수 없고, 이미지를 연속으로 페이징할 수도 없습니다.舒适하게 보려면 마운트를 지원하는 리더기가 필요합니다.

## 操作步骤

1. App Store에서 「만화 캡슐」 다운로드
2. 책장 페이지 사이드바에서 네트워크 책장 추가 → 「123 클라우드 드라이브」 선택 → 로그인 권한 부여
3. 클라우드 드라이브 디렉토리 탐색, 만화 파일이 자동으로 커버월 생성, 클릭하면 바로 읽기

알리 클라우드/바이두 클라우드 마운트와 동일한 경험을 제공하며, 일부 형식의 **스트리밍 로딩** 지원 (전체 파일 다운로드 대기 불필요), 페이지 프리페치, 진행 상황 자동 기록, 长按缓存支持支持离线缓存等功能 제공합니다.

对于EPUB格式和ZIP压缩包支持是最好的，优先推荐这俩格式哈。
ZIP内支持的是把图片放到ZIP内，不支持ZIP内再放EPUB/PDF什么的，这些资源本身也是压缩的，没必要再包在ZIP里了哈。

![](https://mangacapsule.com/images/add-123pan.jpg)

## 为什么网盘党值得配一个直读阅读器

만화 저장 체인은 보통: 리소스 수집 → 클라우드 드라이브 넣기 → 보고 싶을 때……막힘. 막히는 이유는无非 세 가지:

1. **手机空间不够**——一部全集十几个 G，下载完 iPad 就满了
2. **下载太慢**——尤其压缩包大的时候，等半小时才能看上
3. **看完还得删**——删了下次想重温又得再来一遍

直接 읽기 솔루션은 이 세 가지 문제를 한 번에 해결: 파일은 항상 클라우드에 저장, 본 기기에서는 현재 보는 몇 페이지만 캐시. 클라우드 드라이브에 수백 G의 만화库, iPad의 실제 사용량은 2G 미만. 많이 보면 캐시가 커지지만 정리하면 괜찮습니다.

## 支持格式

ZIP、CBZ、CBR、RAR、7Z、PDF、EPUB、MOBI——수집한 리소스는 解압하거나 변환할 필요 없음.

对于EPUB格式和ZIP压缩包支持是最好的，优先推荐这俩格式哈。
ZIP内支持的是把图片放到ZIP内，不支持ZIP内再放EPUB/PDF噢。

## 常见问题 FAQ

**Q：123 云盘免费账号可以直读吗？**
A：可以，免费账号一般够用；但流式加载，如果漫画比较大，还是开付费速度快体验更好。

**Q：和阿里云盘、百度网盘比推荐用哪个存漫画？**
A：都支持的情况下看你的资源在哪。新收的资源如果可以选，阿里云盘和 123 云盘的免费速度体验更好；已经在百度网盘的存量库不用搬，直接挂载就行。多个网盘可以同时挂载。

**Q：安全吗？**
A：授权走 123 云盘官方接口，App 不经手你的账号密码；漫画文件不会上传到任何第三方服务器，阅读记录只在你自己设备和 iCloud。
